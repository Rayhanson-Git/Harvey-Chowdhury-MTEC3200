## Process evaluation

Small build steps made it possible to validate inputs before adding results, then test editing separately. Automated checks establish calculation rules; hosted checks establish observed browser behavior. Neither establishes that the product reduces lateness.

The separate research-method, affinity, insight, persona and POV documents were organized after the build. Keeping their actual dates makes that limitation visible. For a future project, save those artifacts and a brief student explanation at each stage.

The guide in [Presentation/code-defense.md](../Presentation/code-defense.md) explains the file responsibilities and includes practice questions.
