# Project evaluation

This record covers the original LeaveBy project. See the [JimBro project reflection](jimbro/reflection.md) for the subsequent unified web application.

October 20, 2026. This evaluation records decisions and evidence from the repository. It is not a transcript of a student's personal reflection.

## What the project established

The prototype implements the selected transition-planner direction: one commitment, three duration estimates, calculated milestones and editing. The documented interview contrast kept the problem narrower than a general lack of free time. Tests make the arithmetic and error rules reproducible.

## What changed during the build

- The entry screen came first, then calculation, results and editing.
- Full timestamps handle crossing midnight.
- Blank durations remain distinct from zero.
- The audit added copied-code attribution and native color-scheme support.
- Deployment required repairing the service connection, then a certificate issue on the custom domain.
- The separate research artifacts were organized retrospectively on October 20; their dates remain visible.

## What could improve next time

Save the research plan and synthesis artifacts when doing the research, rather than reconstructing them after the build. Keep a prompting log at each step with the actual student explanation. Start hosted browser checks earlier so focus and native-control behavior receive attention alongside arithmetic.

Peer feedback should drive any further interface changes. A successful calculation does not establish that the labels are clear or that users arrive earlier.

## Questions still open

Can users estimate preparation and commute accurately? Do they understand stopping versus leaving? Does the result clarify the next action or encourage more clock watching? Would a saved routine help enough to justify adding persistence?

Personal learning and the live code defense must come from the student. The [code defense guide](../Presentation/code-defense.md) provides an explanation and rehearsal questions.
