# JimBro foundation v1

Version 1.0 · October 20, 2026 · Branch: `revamp/foundation`

JimBro is a working title for one gym companion combining LeaveBy scheduling with GymLog-style logging after a set. The current application remains LeaveBy. This folder records the Milestone 1 foundation; it adds no runtime features.

This is the initial planning baseline, not an application release. Keep the original-file manifest immutable. Record later requirement changes with a dated version entry and matching acceptance updates; use a new version folder for a materially different product direction. Architecture records distinguish a selected direction from a proposed implementation detail.
