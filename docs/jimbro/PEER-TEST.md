# Peer usability test — pending real participants

Use a disposable profile or exported test records. Do not ask participants for sensitive health data. Record actual observations only, including help needed and confusing wording. No peer results are claimed.

| Task | Success criterion | Follow-up question |
|---|---|---|
| Plan before a class/work commitment | Correctly identifies workout cutoff, preparation and leave-by time | What do you think happens at each time? |
| Find a routine that fits | Previews estimate and deliberately adapts/chooses a shorter preset or acknowledges mismatch | What made you confident it fit? |
| Log and correct a set | Saves actual reps/load, finds Edit and corrects it | Did any value or completion state surprise you? |
| Reload during training | Finds the same completed set and accurate deadline | What did you expect to be preserved? |
| Finish early and leave | Keeps completed work; understands reminder closure does not record departure | Is the difference between finish workout and close reminders clear? |
| Find saved work | Uses calendar/list/details; understands progress units | Where would you look next time? |
| Change Jim’s tone and visibility | Finds independent tone/flirtation/motion/visibility controls | Is Jim helpful or distracting? |
| Export a backup | Understands device-local storage and saves a JSON file | What would happen on another device or after clearing site data? |

Capture task outcome, time/help needed if measured, participant wording (with consent), and a prioritized issue list. Then revise and retest. Physical-device keyboard, VoiceOver/TalkBack and real audible alerts need separate observations.
